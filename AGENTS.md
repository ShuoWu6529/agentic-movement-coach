# AGENTS.md

Browser app for the AI Movement Coach pilot. `SPEC.md` is the source of truth; propose changes to it to the owner before editing it.

## Commands (all verified on Node 24.16 / npm 11.13)

```bash
npm ci                 # install exact locked versions
npm run dev            # http://localhost:5173 (runs fetch-models first)
npm run dev:https      # LAN + self-signed cert, for phone camera testing
npm run build          # fetch-models, tsc --noEmit, vite build -> dist/
npm run preview        # serve dist/
npm test               # vitest run (jsdom)
npm run test:watch
npm run typecheck      # tsc --noEmit
npm run lint           # eslint .
npm run check:data     # fails if anything under data/ is tracked by git
npm run fetch-models   # copy MediaPipe wasm, download pose models, verify pinned sha256
```

CI (`.github/workflows/ci.yml`) runs: `npm ci`, `check:data`, `typecheck`, `lint`, `test`, `build`.

## Notes

- **TypeScript is pinned to 6.0.x** because typescript-eslint supports `<6.1`. Don't bump to 7 until it does.
- The npm config here has a release-age cutoff (`before=`). Installs of very new versions fail with `ETARGET`; let npm pick the newest eligible version.
- `public/models/` and `public/wasm/` are generated by `fetch-models` and git-ignored. If the upstream model changes, the sha256 check fails on purpose. Review the change before re-pinning in `scripts/fetch-models.mjs`.
- `src/core/` must stay pure: no React, MediaPipe, `node:*`, or imports from `src/app` / `src/pose`. ESLint enforces this (tests are exempt).
- `data/` (videos, traces, logs, consent records) must never be committed (C-4).
- `spike/` is the separate M0.5 throwaway tool with its own `package.json`. It is ignored by root lint and tests.
- Asset URLs must go through `import.meta.env.BASE_URL` (`base: './'`), so the build works from any subpath.

## Layout

- `src/core/`: pure logic (config schema, load and hash; rule registry; log and trace schemas).
- `src/app/`: React shell (phase reducer, screens, components).
- `public/config/targets.json`: therapist config, fetched with `cache: 'no-store'`.
- `docs/definitions.md`: attempt, repetition, angle, latency and scoring definitions.
